# 音韻分析檢查

安裝 JDK 21 或以上、Python 3，設定 `JAVA_HOME` 後，在專案根目錄執行：

```text
python tests/phonology/run.py
```

檢查介音歸韻與五項觀察值、字組內讀音集合比較、中古條件排序與三 A／B／C 篩選、桑基圖流帶命中。這些檢查不需要字典資料庫或 Android 裝置。

Android 操作驗證項目：

- 查字後逐次切換列表、語言在左、語言在上，勾選字頭，並點字頭查看及繼續開啟資料連結。
- 從猜字下方的「音典小工具」進入五個分析模組；確認中古條件可多選，等可區分三 A／B／C。
- 單字音類產生全部音值與所選音值地圖；字音比較按每個方言點內所選漢字的讀音分類。
- 兩地對應以共同字生成可捲動桑基圖，點流帶顯示兩地同字的讀音。
- 地圖橫豎屏切換後保留中心與縮放，仍能點選地點；關閉後恢復原方向設定。快速開關地圖應能完成背景資源清理。
