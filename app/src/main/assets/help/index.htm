漢字音典使用說明

查一個字的讀音時，先在左上角選「漢字」，輸入字後點放大鏡。想查某個地方的讀音，可在下方選語言，再把顯示範圍切換到「當前語言」。

首頁與主選單

左側標題
默認為「漢字音典」。可在「⚙️設置 → 外觀 → 自定標題」修改。
🏠 首頁
返回字表並清空本次查詢的輸入和語言選擇。
ℹ️ 信息
未選語言時，查看項目介紹、版本和收錄統計。選定語言後，可看地點、分區、作者或維護人、參考文獻、字數與音節數等。資料有提供時，也可開啟原始字表連結及同音字表。點某條讀音旁的語言名稱，也可看該語言資料。
︙ 主選單
開啟「⚙️設置」「🌏地圖」「📖生字本」「📚 詞表」「猜方言」「猜字」「音典小工具」「方言連結」「❔幫助」或「❕關於」。方言相似度在「方言連結」內。「關於」有版本及下載連結。

猜字根據字形或讀音提示猜一個漢字。猜方言則根據指定漢字的讀音或相對地理位置猜方言。

查詢方式與例子

左上角下拉框決定右側輸入框會查甚麼。輸入後可點放大鏡，或按鍵盤上的搜尋鍵。

漢字｜查一個或多個字的讀音
例如輸入「心新」，查看兩個字的讀音。可直接輸入繁體或簡體。需要一併查看異體時，在查詢欄的「…」打開「顯示異體字」。
讀音｜找同音字
先在下方「輸入或選擇語言」選一個語言點，再按該語言使用的讀音格式輸入音節。查到字後，也可以點某條讀音，從選單反查該語言的同音字。
註釋｜按字表的註釋查字
輸入要找的繁體或簡體詞語。要同時含有幾段文字，可用空格隔開。
辭典｜按辭典內容反查字
在下方選一部辭典或「全部辭典」，再輸入要找的正文或釋義片段。若只想看命中的字，可將顯示範圍切到「僅漢字」。

鍵盤與讀音格式

  • ⌨️ 系統輸入法。使用手機的輸入法直接打字。切回此項即可恢復一般輸入。
  • 提示讀音。選定語言後，輸入漢字可查看該語言的讀音候選，方便確認查詢格式。
  • 字形檢索。從 ⌨️ 選擇字形描述、部件、兩分、筆畫、部首餘筆、五筆或倉頡等項目，輸入對應的部件或編碼後，從候選中選字。可用項目以選單為準。
  • 讀音格式。廣韻、普通話、香港粵語、臺灣閩南語、東干甘肅話、越南語、朝鮮語等可在「設置 → 語言」查看適用的顯示或輸入格式。查不到時，可先查一個已知讀音的字，再由該讀音反查同音字。

語言範圍與查詢選項

下方的顯示範圍

  • 顯示全部／僅漢字。查看各語言讀音，或只看命中的漢字。
  • 當前語言／推薦語言。只看已選語言，或依檔案中的推薦人篩選。
  • 自選語言。建立自己的方案與分區，選擇語言、排列順序及設定顏色。操作見下方「自選語言、分區與 Excel」。
  • 方言分區／行政區／維護人。按目前的分區方案、省份與行政層級，或作者、錄入人、維護人縮小範圍。

查詢欄的「…」

  • 漢字檢索範圍。限定查詢結果的字集，例如《廣韻》《說文解字》《集韻》《康熙字典》或常用字表。查不全時可切回「不限」。
  • 方言島／歷史音。可只顯示或隱藏方言島、歷史音，也可選「不限」。
  • 注釋結果合併顯示。默認不勾選，只在「註釋」查詢的列表生效。啟用後按語言集中顯示，詳細格式見下方說明。
  • 長文本注音。先選定語言，在「…」啟用「長文本注音」，再用「漢字」模式查詢一段文字，可在結果上方查看注音。
  • 切換到精簡界面。收起上欄和查詢選項。點搜尋欄旁出現的按鈕即可恢復。

自選語言、分區與 Excel

先在顯示範圍選「自選語言」。下方一行從左到右是「方案 | 分區」、語言數、去重、📥 導入、📤 導出。選擇方案和分區後，查詢只使用目前範圍內能匹配到的語言。

建立方案與分區

  1. 點左側「方案 | 分區」，下拉面板左欄是方案，右欄是該方案的分區。點一列選中，以背景色標示。
  2. 兩欄底部各有「新建」「改名」「刪除」。新建方案後，再在右欄新建分區；名稱可用 A-B-C 表示層級，列表會縮排顯示。
  3. 按住列右邊的 ☰ 拖動排序。方案可自由調序；分區只能在同一父分區下移動，移動父分區時會連同子分區一起移動，語言記錄的排列亦隨之更新。
  4. 選「全部分區」查看目前方案的所有分區。最後一個方案不能刪除；系統建立的「未分區」不能改名或刪除。刪除普通分區會一併移除該分支的語言選擇，請先確認或導出備份。

分區新增子分類後，原本直接放在父分區的語言會歸入該級的「未分區」。例如 A-B 原有 1、2、3、4、5，再建立 A-B-C 並放入 1、2、3，餘下 4、5 就在 A-B-未分區。選 A-B 仍可查看整個分支。同一語言可以分別放入不同子分區；已歸入該分支具體子分區的語言，會退出父級「未分區」。

加入語言、調序與設色

  1. 點中間的語言數，開啟左右雙欄。左欄是已選記錄，右欄可搜尋所有已收錄語言，勾選後加入左欄。目前範圍已選的語言會打勾；點其名稱可定位左欄。
  2. 左欄取消勾選可移除此記錄，按住 ☰ 可調整順序。點語言名稱可選「更換分區」或「移除此記錄」。左上方的分區名稱可切換範圍或新建分區。
  3. 點語言右側色塊設定單條記錄顏色；點左欄頂端色塊，設定目前分區或整個方案的顏色。調色盤可調色相、飽和度與明度，也可輸入 #RRGGBB。
  4. 單條記錄的「跟隨分區顏色」可取消單獨設色。更改整體顏色時，若已有單獨配色，可選保留，或用「全部統一／全部恢復繼承」清除該範圍的覆蓋色。

使用自選配色：勾選後，查詢列表、表格及字表地圖採用自選顏色，標籤文字固定為白色；取消後採用音典原配色，已設定的顏色仍保留。修改或導入顏色時會自動啟用。顏色依「單條記錄 → 所屬分區 → 上級分區 → 方案 → 音典原色」取用，目前自選色為單色。

去重：默認關閉，保留同一語言在不同分區的記錄。勾選後，按目前排列保留最先出現的一條；這只改變顯示，不會刪除原始選擇。語言數按實際可匹配且符合篩選的語言計算，未去重時另列記錄數。

📥 導入與 📤 導出

  1. 點 📤，選一個方案或「全部語言模板」，再勾選導出哪些記錄、哪些輔助資訊，最後選儲存位置。可先導出模板，在電腦編輯後導入。
  2. 導出的 .xlsx 只有一個「自選分區」工作表，基本欄位為「語言」「自選分區」「自選顏色」。語言用完整名稱匹配，分區用 - 分級，顏色填 #RRGGBB，留空則跟隨上級或音典原色。讀取的是儲存格文字，並非 Excel 填充色。
  3. 可附加簡稱、地圖集二分區與顏色、音典分區與顏色、地點及經緯度。這些是製表參考，導入時不會用來替換自選分區或自選顏色，也不要求你的分區與內置方案相同。
  4. 點 📥 選取 .xlsx。方案名稱預設為檔名，確認前可改名。預覽會列出記錄數與未匹配名稱；未匹配記錄會保留，但不參與查詢。同名方案須確認更新，確認後會整體替換原方案。

Excel 保留記錄的先後次序及重複行。一般單表的分區顏色取該分支記錄中出現最多的非空顏色，同票取先出現者，其餘顏色保留為單獨配色。導出時會把繼承後的自選色寫到各行，空分區及獨立的分區排序不另存；因此此表適合交換語言、分區及顏色，並非完整設置備份。導入不會修改內置字表資料庫。

注釋結果合併顯示

在查詢欄「…」勾選「注釋結果合併顯示」，再用「註釋」搜尋。此選項默認關閉，只改變註釋查詢的列表；漢字、讀音、辭典查詢及表格維持原來的展示方式。

啟用後，結果集中在一個「□」字頭下，依語言排列，同一語言的結果相鄰；使用自選語言時依方案記錄順序。每條讀音前顯示 [漢字] 音標及解釋，方括號內漢字加粗。原字就是「□」時不顯示方括號，直接顯示音標和解釋。

列表、表格與字頭連結

  1. 查到結果後，點查詢欄右端、在「…」右邊的方格按鈕，可依次切換「列表 → 語言在左 → 語言在上 → 列表」。
  2. 在表格上方的漢字列勾選要比較的字。取消勾選即可從表格移除該字，表格可橫向滑動。
  3. 在列表點字頭旁的連結，或在表格點漢字，查看 Unicode、《說文》《集韻》《康熙》等已收錄資料，也可開啟該字的讀音地圖。
  4. 點表格中的讀音格可看讀音詳情，點表格角落的 📤 可複製或匯出 TSV。列表中點讀音可複製、反查同音字或查看語言信息。

列表不列出沒有實際讀音的語言。表格則依目前勾選的漢字判斷：一個讀音都沒有的語言不顯示；只缺部分字時，該語言仍保留，空格沿用系統的空缺符號。

詞表與生字本

📚 詞表

從右上角主選單的「生字本」下方進入。目前顯示「數據庫正在建設中……」，詞表查詢與篩選尚未開放。主選單同一位置的「↩️ 字表」可返回查字頁。

📖 生字本

點列表字頭旁的五角星，可收藏漢字並加筆記。從主選單打開生字本後，可再次查字或修改筆記。頁面選單提供導出、導入和清空，可把備份文件帶到新手機再導入。

音典小工具

從主選單進入。方言項目可選聲母、韻母、聲調、無聲調音節或完整音節。拆分時，介音歸入韻母。

中古→方言
選一個方言和「中古項目」「方言項目」，生成對應表，查看中古音類在該方言中的讀法。點「例字／詳情」，同時查看例字、讀音和中古地位。
方言→中古
用同樣的項目反查某個方言音類有哪些中古來源。兩頁的「中古條件」均可多選。同一項任一選值符合即可，不同項須同時符合。
兩地對應
從候選選出兩個語言點，選觀察項目，再點「生成桑基圖」。連線由兩地共同收錄的漢字統計，越寬代表該對應涉及的字越多。點線可看例字。「桑基圖設定」可限制連線和節點的最少字數，或忽略多音節讀音。
單字音類
輸入一個字，勾選繁簡候選及想看的項目。可繪製全部音值，也可透過「音值 ▾」多選要顯示的音值。點地圖上的標記可看該地的讀音。
字音比較
輸入多個字，勾選要比較的字和項目，再點「比較字音」。結果按各地的同音情況分組，可打開「全部地圖」或查看其中一組的詳情與地圖。

小工具的地圖頂欄可切換橫屏、豎屏；「歷史音」「方言島」默認開啟，可手動關閉。這兩個開關只用於小工具地圖。

鳴謝：部分功能構思與展示方式參考了 古音小鏡·歷史語言學 與 方音圖鑑，感謝相關網站的建設與分享。

便携Praat

  1. 在「音典小工具」打開「便携Praat」，點「開始錄音」或「導入音頻」。第一次錄音要允許麥克風權限。導入雙聲道音頻時，選「左聲道」或「右聲道」。
  2. 上方是波形，下方是頻譜。點頻譜可查看所在位置的頻率。拖曳選取一段，雙指或底部按鈕可縮放，滑桿可移動查看位置。
  3. 點「播放」聽整段已分析的音頻。有選區時用「播放選區」。長音頻目前只分析前 120 秒。
  4. 右上的「設置」可開關頻譜、基頻、強度、共振峰與聲門脈衝。要看語音的聲調走勢，可先打開「基頻」。

設置

外觀
可修改標題、字體和字形標準。字形標準包括默認、大陸、香港、臺灣、日本和韓國；可安裝字體包補足缺字。
分區方案
切換後，「方言分區」篩選與語言詳情依所選方案顯示。可用方案以當前版本的選單為準。
調類與調值
調類可用拼音數字、八聲、四聲、漢字或四角標記，也可與調值並排或隱藏。調值可用曲線、數字或隱藏。
各語言的顯示
可分別設定廣韻、中唐（韻圖）、中原音韻、普通話、香港粵語、臺灣閩南語、東干甘肅話、越南語、朝鮮語和日語等的顯示方式。
